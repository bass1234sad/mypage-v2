เป้าหมายและแนวทางการเรียนรู้

1. เหตุผลที่อยากเรียน Full stack web development :
เพราะทำให้เราเข้าใจระบบครบวงจรตั้งแต่หน้าบ้านถึงหลังบ้าน ทำให้ปั้นเว็บแอปจริงได้ด้วยตัวคนเดียว เพิ่มโอกาสงานและค่าตอบแทนสูง พร้อมสื่อสารกับทุกทีมได้

2. ความคาดหวังต่อวิชานี้คือ :
สร้างโปรเจกต์จริงได้ครบวงจร เชื่อมหน้าบ้าน หลังบ้าน และดาต้าเบส จนได้เว็บแอปที่ใช้งานได้จริง เข้าใจภาพรวมสถาปัตยกรรมระบบ: ออกแบบระบบและ API เป็น

3. อะไรคือจุดอ่อนที่ตนเองต้องพัฒนาเกี่ยวกับทักษะ Programming และ แนวทางการพัฒนา :
จุดอ่อนคือยังจำไม่ค่อยได้ บางทีก็ลืม ๆ ไปเลยทั้งที่เพิ่งทำไปเมื่อกี้ และพอจะทำก็ไม่รู้ต้องเริ่มจากไหนอะไรก่อน
แนวทางการพัฒนาคือ ฝึกทำบ่อย ๆ เขียนบ่อย ๆ ศึกษาหาข้อมูลจากเน็ต ใช้ AI ช่วยแก้ปัญหาในบางเรื่อง ใช้ AI เป็นเครื่องทุ่นแรงเป็นเหมือนผู้ช่วยคนนึง
